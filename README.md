# Lab 11 - Unit Testing with JUnit

This lab covers unit testing fundamentals using JUnit 5.

## Contents

The main lab materials are located in the `unit-testing-junit/` directory, which contains:

- A complete Maven project with JUnit 5 setup
- Detailed documentation on JUnit 5 annotations and assertions
- A practical exercise implementing a MathChampionship class
- Test-driven development (TDD) examples
- Configuration for code coverage using JaCoCo

## Getting Started

Navigate to the `unit-testing-junit/` directory to begin the lab:

```bash
cd unit-testing-junit
```

See the [unit-testing-junit README](unit-testing-junit/README.md) for detailed instructions.
